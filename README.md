# NAVARIT Portfolio

Game-inspired personal portfolio for **Navarit Rodsamrit** — Application Support Engineer at Gosoft · CP ALL.

Visual direction leans into competitive-game marketing sites: dark atmosphere, sharp clipped CTAs, condensed display type, and high-contrast red accents.

## Stack

- Vite + React + TypeScript
- Framer Motion
- Custom CSS (Oswald + Barlow)

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Content

Profile, experience, skills, projects, and certifications live in `src/data/content.ts`.
